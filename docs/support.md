# Support

## Getting help

This C++ rewrite does not yet have a public repository of its own (see the note on `repo_url` in
`mkdocs.yml`), so there is no issue tracker link to give here yet. Until one exists, direct questions to
the project owner.

For the original Python HiCExplorer that this project rewrites, questions, bug reports and feature
requests go to its GitHub issue tracker:
[https://github.com/deeptools/HiCExplorer/issues](https://github.com/deeptools/HiCExplorer/issues) (note
that this does not cover the C++ rewrite documented on this site). In the past, questions were also
answered on Biostars under the tag `hicexplorer`
([https://www.biostars.org/t/hicexplorer/](https://www.biostars.org/t/hicexplorer/)) and on the
[deepTools mailing list](https://groups.google.com/forum/#!forum/deeptools); GitHub issues are the
preferred channel today.
