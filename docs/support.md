# Support

## Getting help

Questions, bug reports and feature requests go to the GitHub issue tracker:
[https://github.com/deeptools/HiCExplorer/issues](https://github.com/deeptools/HiCExplorer/issues).
Questions were also answered on Biostars under the tag `hicexplorer`
([https://www.biostars.org/t/hicexplorer/](https://www.biostars.org/t/hicexplorer/)) and on the
[deepTools mailing list](https://groups.google.com/forum/#!forum/deeptools).
